# Building the video in Remotion

Remotion renders React components frame by frame, which gives frame-accurate sync, vector-sharp diagrams and fully editable source. The template in `assets/remotion-template` is a proven structure: scenes are SVG components, all times come from cues anchored to the narration, and a Stage assembles scenes, captions, voice, music and effects.

## Project layout

```
my-video/
├── video.spec.json          scenes, captions and cues per video (you write this)
├── src/
│   ├── Root.tsx             registers <Name> and <Name>Clean per video (don't edit)
│   ├── videos.tsx           list of videos: id, name, scene map, sound effects
│   ├── data/timeline.json   generated by build_timeline.mjs (don't hand-edit)
│   ├── lib/anim.ts          easing, pr(), camera, pointAt(), cue()
│   ├── lib/theme.ts         colour and font tokens (set from the project's identity)
│   ├── components/Stage.tsx scene cross-fades, captions, audio and ducking
│   ├── components/kit.tsx   Box, Wire, Tile, Tag, Kicker, StepChip, Counter, Bar, Wordmark, Logo…
│   └── scenes/*.tsx         one component per storyboard scene
├── public/
│   ├── audio/voice/takes/   raw takes (input)
│   ├── audio/voice/         cleaned takes (audio_tools.py voice)
│   ├── audio/music/, sfx/   generated (audio_tools.py music / sfx)
│   └── img/                 logos, photos, screenshots
├── scripts/                 transcribe, build_timeline, audio_tools, stills, render, master, qa
└── out/                     .srt files, stills, qa frames, final MP4s
```

## Command sequence

Run from the project folder. Use `python3` or `py` if `python` isn't the right command.

```bash
node <skill>/scripts/check_env.mjs
node <skill>/scripts/init_project.mjs my-video
cd my-video && npm install
# takes into public/audio/voice/takes/ (scratch voice is fine to start)
node scripts/transcribe.mjs                 # -> scripts/words.json; read the transcripts
python scripts/audio_tools.py voice sfx     # cleaned takes + effect palette
# write video.spec.json, then:
node scripts/build_timeline.mjs             # -> src/data/timeline.json, out/*.srt; fix every warning
python scripts/audio_tools.py music         # music beds from the timeline
# write scenes + videos.tsx, then iterate:
npx tsc --noEmit -p .
node scripts/stills.mjs Pitch --cues        # look at every still; fix; repeat
node scripts/render.mjs Pitch out/Project_Pitch_captioned.mp4
node scripts/render.mjs PitchClean out/Project_Pitch_clean.mp4 --audio-from out/Project_Pitch_captioned.mp4
node scripts/qa.mjs out/Project_Pitch_captioned.mp4 --max 175 --srt out/pitch.srt
```

`npx remotion studio` gives a live preview with a scrubber, useful when the student wants to watch along. Use `--no-open` in headless setups.

When takes change: replace the WAVs, rerun transcribe → audio_tools voice → build_timeline → audio_tools music. Scenes need no edits because their times come from cues.

## video.spec.json

```json
{
  "fps": 30,
  "videos": {
    "pitch": {
      "takes": ["Pitch_P1", "Pitch_P2", "Pitch_P3"],
      "lead": 0.3, "gap": 0.9, "tail": 4.5,
      "maxDuration": 175,
      "placement": {"Pitch_P3": 120.0},
      "music": {"mood": "calm", "fullAt": "yet", "endAt": "endname"},
      "scenes": {"S01": null, "S02": "Pitch_P1: that's why", "S03": "Pitch_P1: both are"},
      "captions": {"Pitch_P1": ["Caption sentence one.", "Caption sentence two."]},
      "cues": {"yet": "Pitch_P1: yet", "name": "Pitch_P1: cerberus", "secondKey": "Pitch_P2: key #2"}
    }
  }
}
```

- **takes:** file stems in `public/audio/voice/takes/`, placed back to back (`lead`, then each take, then `gap` seconds of air). `placement` pins a take to an absolute time. Total = last word + `tail`.
- **scenes:** ordered; the first is `null` (starts at 0). Each later scene starts 0.3 s before its anchor phrase (`sceneLead` to change).
- **captions:** the caption-version sentences per take, in order. They are aligned to the transcript automatically (robust to whisper mistakes); write them with correct spelling and punctuation. One or two lines each (≤ ~90 characters).
- **cues:** named times used by scenes. Anchor to the word the visual belongs to. Use the transcript's spelling of the word (whisper may write "MLKEM", "18" or a misheard name); the builder falls back to the closest match with a warning, but resolve every warning, because a wrong cue means a wrong frame.
- **music:** `false` to disable; `mood` is `calm`, `bright` or `tense`; `fullAt` and `endAt` are cue names (when the bed comes in, and when it resolves under the end card).

## Writing scenes

```tsx
export const S04: React.FC<{s: SceneDef}> = ({s}) => {
  const {t, cues: c} = useT();                   // t = seconds since video start
  const name = cue(c, 'name');                    // throws on a typo instead of silently using 0
  const reveal = pr(t, name - 0.3, 0.9);          // 0→1 over 0.9 s, starting 0.3 s before the word
  return (
    <g>
      <Night />
      <Wordmark x={180} y={470} text="CERBRUS" accent="–PQ" p={reveal} />
      <Tag x={180} y={560} text="Target" op={pr(t, cue(c, 'clock'), 0.5)} />
    </g>
  );
};
```

Patterns:
- **Progress, not keyframes:** every animated value is `pr(t, start, duration, easing)` mapped into a position, opacity or draw amount. `win(t, s, e)` for things that appear and leave.
- **Start just before the word** (0.1–0.3 s) so the element is readable as the word lands.
- **Highlight with `hl`** on Box (a 0→1 ring), and fade it out when the narration moves on: `pr(t, a, 0.35) * (1 - pr(t, b, 0.5))`.
- **Camera:** draw a large diagram once inside `<g transform={camT(cam)}>`, with `cam = camAt(t, init, keys)`; keys tied to cues. Screen-space overlays (step chips, legends) go outside that group.
- **Tokens on wires:** `const [x, y] = pointAt(points, EIO(progress))` on the same points the Wire uses.
- **Scene boundaries:** scenes cross-fade for 0.5 s, so the outgoing scene is still visible at the start of the next. If a scene does its own wipe/flood, add it to `noFade` and clip-reveal its content.
- **Data in, not hard-coded:** keep numbers in a small `data.ts` next to the scenes, copied from the claims ledger, so a correction is one edit.
- Animate only with frame-derived values. CSS transitions/animations and `setTimeout` don't render correctly in Remotion.

## Sound effects per video

In `src/videos.tsx`, `sfx: (c) => [{at: c.name - 0.05, name: 'motif', vol: 0.3}, …]`. Available names after `audio_tools.py sfx`: tick, tick_soft, whoosh, click, crack, pop, thunk, stamp, riser, motif, ok, notify. Keep one effect per idea at most, volumes 0.12–0.35, and put the brand `motif` on the name reveal and the end card.

## Footage, screenshots and logos

- Put files in `public/img/` or `public/video/` and reference them with `staticFile()`.
- Logos inside SVG scenes: `<Logo src="img/uni.svg" x y w h />`.
- Screen recordings / demo footage: render with Remotion's video component inside an `AbsoluteFill` layer above or beside the SVG (for Remotion 4: `OffthreadVideo` from `remotion`, or `Video` from `@remotion/media` in newer versions; check the current docs). Trim with its start/end props, mute it if the narration covers it, and add zoom callouts as an SVG overlay.
- Photos: frame them like the diagram style (rounded corners, thin stroke), with labelled callouts drawn in SVG.

## Fonts

The template loads Google Fonts through `@remotion/google-fonts/<Family>` (needs internet at render time). For the poster's own fonts or offline work, copy `.woff2` files to `public/fonts/` and load them once:

```ts
import {continueRender, delayRender, staticFile} from 'remotion';
const h = delayRender('fonts');
const f = new FontFace('Poster Sans', `url(${staticFile('fonts/poster-sans.woff2')}) format('woff2')`, {weight: '700'});
(document.fonts as any).add(f);
f.load().then(() => continueRender(h));
```

## Bugs that cost the most time

These are from real builds; check them in every stills pass.
- **Text wider than expected.** Display fonts vary a lot in width. Never size boxes, clips or underlines from character counts for important text; leave generous room, or measure with `@remotion/layout-utils` (`measureText`).
- **Element appears before its word,** or a token departs before its source exists. Anchor to the right cue, not the scene start.
- **Moving token crossing a block's face.** Tokens ride wires between blocks; never draw a path through a box.
- **Labels colliding** with neighbouring tiles, the caption band or the frame edge, especially after camera zooms. Check stills at the zoomed moments.
- **Empty frames during camera moves** (zoomed into nothing). Every camera key should frame something labelled.
- **Last scene ends abruptly.** Leave `tail` ≥ 4 s for the end card and music resolve.
- **A typo in a cue name** silently becoming 0: use `cue(c, 'name')`, which throws.

## Other formats and engines

- **Vertical (9:16) or square:** change width/height in Root.tsx and design layouts for it from the start; keep captions above platform UI (bottom 20 %).
- **4K:** render at 1920×1080 and pass `scale: 2` to renderMedia only if required; it quadruples render time.
- **Other engines:** Motion Canvas or Manim (maths-heavy explainers) work too, but this skill's tooling (timeline, stills, render, QA) targets Remotion. Prefer Remotion unless the student already has a project in another engine.
